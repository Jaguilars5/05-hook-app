## 📚 Sobre el Curso

El curso cubre de manera integral React y sus Hooks, desde conceptos básicos hasta avanzados:

### Contenido Cubierto en Este Repositorio

#### Fundamentos de Hooks

- ✅ **useState**: Manejo de estado local
- ✅ **useEffect**: Efectos secundarios y ciclo de vida
- ✅ **useRef**: Referencias al DOM
- ✅ **useLayoutEffect**: Efectos de layout síncronos

#### Optimización y Performance

- ✅ **useMemo**: Memorización de valores calculados
- ✅ **React.memo**: Prevención de re-renders innecesarios
- ✅ **useCallback**: Memorización de funciones

#### Estado Avanzado

- ✅ **useReducer**: Gestión de estado complejo
- ✅ **useContext**: Estado global y Context API

#### Conceptos Adicionales

- ✅ Custom Hooks
- ✅ Testing de Hooks con Jest
- ✅ React Router DOM
- ✅ Integración con APIs
- ✅ Buenas prácticas y patrones

## 📝 Notas del Estudiante

### Lo que Aprendí

- **useState y useEffect** son la base fundamental de React Hooks
- Los **custom hooks** permiten reutilizar lógica de manera elegante
- La **optimización** con memo y useCallback es crucial en apps grandes
- **useReducer** es ideal para estado complejo con múltiples acciones
- **useContext** simplifica enormemente el paso de props

### Mejores Prácticas Aplicadas

- 📦 Separación de concerns (UI vs Lógica)
- 🎣 Custom hooks para lógica reutilizable
- ⚡ Optimización solo cuando es necesaria
- 🧪 Tests para hooks críticos
- 📁 Organización por features
- 💅 Código limpio y legible
